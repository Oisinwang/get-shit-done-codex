# GSD Codex 문서

이 폴더는 GSD Codex fork의 한국어 문서 입구입니다. 이 fork는 Codex-first입니다. 공개 계약의 중심은 `AGENTS.md`, `.codex/`, `$gsd-*`, `agents_md_path`, `generate-agents-md`, Codex 세션 경로입니다.

게시된 패키지는 다음 명령으로 설치합니다.

```bash
npx @oisinwang/get-shit-done-codex@latest
```
