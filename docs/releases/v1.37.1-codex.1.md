# v1.37.1-codex.1

First public release of the independent Codex-first fork.

## Highlights

- Fork identity is now independent from upstream `gsd-build/get-shit-done`
- `AGENTS.md`, `.codex/`, `$gsd-*`, `agents_md_path`, and `generate-agents-*` are the primary public contract
- Session profiling reads `~/.codex/sessions`
- Legacy Claude-first names remain only as compatibility shims
- README and release-facing docs now describe the project as a Codex-first fork
- Line-ending policy is now tracked with `.gitattributes`

## Install Verification Snapshot
